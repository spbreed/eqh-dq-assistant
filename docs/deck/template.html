Workflow

  1. Land. 8 health plans, state HIEs and the EHR/CareEmpower drop daily files into the S3 bronze (raw) zone (47 feeds, each with its own quirks).
  2. Catalogue. The Glue Data Catalog registers raw and silver tables and their schemas.
  3. Conform & check. Glue jobs turn raw files into silver Parquet; Glue Data Quality rulesets test them.
  4. Model (gold). Redshift loads core, then builds marts and late-binding views.
  5. Deliver. Payer submissions, practice scorecards, the CareEmpower panel feed and datashares go out.

The target: a governed, read-only data assistant

Find & explain

"Which dataset should I use…", plain-language descriptions, business glossary. AI text is labelled AI draft – not yet approved until a steward approves it.

Trace & impact

Table- and column-level lineage across late-binding views, Spectrum, datashares and extracts. Impact ranked: payer submissions › CareEmpower › practice files › finance › marts.

Watch quality

Daily issues by payer and state: stale feeds, volume drops, nulls, duplicates, orphans, overlaps, invalid values, rule failures, schema drift.

Draft documentation

AI drafts descriptions and flags outdated docs. Stewards approve, edit or reject: the only write path, and it's audited.

Stay safe

Refuses any change to data, schemas or pipelines. Shows metadata and aggregates only, never row data. restricted_bh data is hidden from other users.

Workflow

  1. Nightly metadata pipeline
  2. Trigger. EventBridge Scheduler starts the Step Functions chain at 06:00 (Phoenix).
  3. Harvest. Fargate jobs profile the data (aggregates only), harvest the catalogue, parse SQL lineage and detect DQ issues and drift.
  4. Enrich & store. Bedrock drafts documentation and Titan embeds it. Everything is written to the metadata store.
  5. Ask the assistant
  6. Sign in. Users log in through Cognito. CloudFront and WAF front the CloudFront-only ALB.
  7. Reason. The agent calls 10 read-only tools on the metadata store. The model runs on Bedrock with Guardrails.
  8. Answer & govern. It streams a cited answer. Stewards approve drafts, the only write path, which is limited to metadata.

Security, governance & cost

Trustworthy by design

  • Infrastructure as code only (AWS CDK, 8 stacks); least-privilege roles with no wildcards
  • KMS encryption everywhere; databases private; CloudTrail and model-invocation logging on
  • Bedrock Guardrail (blocked topic: changing data/schemas/pipelines; PII masking); read-only tools
  • Cognito groups drive entitlements: restricted_bh data is hidden from others
  • Automated PHI-guard test: no row-level values in the store, prompts or logs
