# eqh-dq-assistant

**▶ View the pitch deck:** https://rawcdn.githack.com/spbreed/eqh-dq-assistant/refs/heads/main/eqh-dq-assistant.html#/1

**AI Data Quality Assistant — pilot.** A governed, read-only assistant over the metadata and data-quality results of
a Medicaid-first value-based-care data platform on AWS. It answers questions, explains assets, traces lineage and
impact, summarises DQ issues and drafts documentation for steward review. It never modifies schemas, catalog entries,
pipelines or data. **Prototype – synthetic data only.**

## What's in the box
| Path | What |
|---|---|
| `infra/` | CDK v2 (Python) app, 8 stacks: Security (KMS, roles, **$300 budget + alerts + automatic deny**, CloudTrail, Bedrock logging) · Network · Image (CodeBuild/ECR) · DataPlatform (S3 medallion, Glue, Redshift Serverless + RPU limit) · MetadataStore (Aurora PG16 + pgvector, Data API) · Pipeline (Fargate jobs, Step Functions, Scheduler, SNS) · Assistant (Fargate, ALB, CloudFront, WAF, Cognito, Guardrail) · Observability |
| `datagen/` | Deterministic synthetic EQH-style platform: 8 fictitious payers × 5 feeds with quirks, 19 silver entities (≈ 3.4 M rows), Redshift marts/late-binding views/datashares, glossary, extract inventory, **14 planted defects** (`seeded_defects.yaml`), 21-day simulation, usage simulator, Glue DQ rulesets, live demo day |
| `jobs/` | `profiler` (aggregates only) → `daily_sync` (harvest, sqlglot lineage, drift, segmented DQ issues, embeddings) → `enrich` (LLM documentation drafts) · `common/` Data API clients, Bedrock Responses API client (SigV4, bedrock-mantle), embeddings |
| `metadata_store/` | migrations 001 (reference schema) + 002 (pilot extensions), least-privilege DB roles |
| `assistant/` | FastAPI service: chat (SSE), asset page (Cytoscape lineage), steward review queue; 10 read-only tools; system prompt |
| `eval/` | 74 golden questions generated from ground truth; harness scoring tool calls, correctness (LLM judge), citations, refusals/entitlements, latency |
| `tests/` | unit tests + **PHI-guard** test (no row values in store, prompts, tool results or logs) |
| `scripts/` | `verify_phase0..8.sh`, `security_selfcheck.py`, `run_task.sh`, `build_image.sh`, pause/resume, destroy, `gen_resources.py`, `build_deck.py` |

## Quick start
```bash
make venv && source scripts/env.sh     # region, venv, PYTHONPATH (credentials come from your AWS profile / env)
make bootstrap image deploy-all        # 🛑 each deploy is an approval checkpoint
make seed simulate                     # data, 21 simulated days, detection, enrichment
make eval verify                       # eval report + phase checks
make simulate-day N=22 INJECT=D07      # live demo day
make pause | make resume | make destroy
```
